# Changelog

All notable changes to this fork are documented here.

## [2.0.0] — 2026-08-31

### Added

- Continuous prepare → perform → judge → learn operating loop.
- Relevant accepted-skill retrieval and applicability-boundary checks.
- Hash-chained observable experience ledger.
- Quarantined candidate lifecycle with versioned provenance.
- Exact skill-artifact hashing and version-bound review receipts.
- Three distinct review gates: evidence/scope, evaluation/usefulness, and
  safety/governance.
- Baseline/no-skill replay, positive/negative/regression/safety eval templates.
- Probation, Beta-smoothed reliability, owner approval, opt-in low-risk
  auto-activation, automatic retirement, revision invalidation, and rollback.
- Bounded externally triggered autonomous curriculum protocol.
- Clean-context candidate-author, triple-reviewer, and curriculum-planner
  prompt briefs plus a bounded trigger envelope template.
- TeamON One integration profile using existing Memory, Context, World, Task,
  WorkRun, immutable composition, and owner authority boundaries.
- Host-signed approval receipts with one-time nonces and immutable-ledger
  anchoring; explicit local-manual mode only as an opt-in.
- Deterministic next-action and evidence-backed curriculum queues.
- Standard-library lifecycle CLI, reports, audits, secret scanning, Agent Skills
  validation, repository/link validation, 33 initial tests, and cross-platform
  CI.
- Security policy and contribution requirements.

### Changed

- Upgraded the core skill, `AGENTS.md`, and Cursor rule from post-task golden-path
  capture to a full measured learning lifecycle.
- Updated installation and plugin metadata to target this fork.
- Expanded harvested-skill requirements with provenance, scope, evaluation,
  lifecycle, safety, and rollback.

### Preserved

- The upstream golden-path insight, failure capture, tool-neutral Agent Skills
  compatibility, and MIT attribution.
